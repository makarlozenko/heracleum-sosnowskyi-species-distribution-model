# Борщевик Сосновского: данные для ML в Литве

Работаем с **9 файлами в `data/model/`**. Полная выгрузка, дубликаты,
старые скрипты и сложный просмотрщик перенесены в `archive/`.

Для продолжения работы на другом компьютере установите Git и
[Git LFS](https://git-lfs.com/), затем:

```sh
git lfs install
git clone https://github.com/makarlozenko/heracleum-sosnowskyi-species-distribution-model.git
cd heracleum-sosnowskyi-species-distribution-model
git lfs pull
```

Все 9 рабочих файлов данных включены в репозиторий. Большой
`infrastructure.gpkg` хранится через Git LFS. `archive/`, локальные библиотеки,
история R и настройки RStudio не публикуются.

Откройте `hogweed.Rproj`, затем `view_data.R`. Выполняйте блоки по очереди
через **Ctrl+Enter** в RStudio. Нужны только `sf` и `terra`:

```r
install.packages(c("sf", "terra")) # только если пакеты ещё не установлены
source("view_data.R", encoding = "UTF-8") # или выполняйте блоки по очереди
```

Таблицы: `View(presence)`, `View(gbif)`, `View(ml_example)`.
Карты появляются во вкладке **Plots**; предыдущие карты доступны стрелками.

| Файл в `data/model/` | Для чего нужен в ML |
|---|---|
| `presence.csv` | 4 767 регистраций INVA: места присутствия вида, `y = 1` |
| `inva_polygons.gpkg` | Полигоны только борщевика: все 4 962 записи со статусами и флагами качества; для определения занятых ячеек |
| `gbif_check.csv` | 180 записей для возможной внешней проверки; отдельно от обучения |
| `boundary.geojson` | Граница области моделирования и маска Литвы |
| `climate.tif` | 6 признаков: BIO1, BIO4, BIO12, BIO15, BIO8 и BIO13; WorldClim 1970–2000 |
| `elevation.tif` | Высота над уровнем моря, м |
| `land_cover.tif` | CORINE 2018, 100 м: категории земного покрова |
| `land_cover_classes.csv` | Расшифровка категорий CORINE; сама таблица не является признаком |
| `infrastructure.gpkg` | Только дороги, водотоки и поселения; из них получаем расстояния и плотности |

Как из этого получить обучающую таблицу:

1. Проверить статусы, `polygon_valid` и дубликаты присутствий. Точки INVA получены из полигонов.
2. Сделать сетку **1 × 1 км, EPSG:3346** и маску Литвы. Одна строка = одна ячейка; одно присутствие на ячейку.
3. Собрать **X**: климат, высоту, доли типов земного покрова, расстояния до дорог, водотоков и поселений.
4. Добавить фон / псевдоотсутствия: **y = 1** — присутствие, **y = 0** — фон, а не подтверждённое отсутствие.
5. Разделить данные **пространственно**, затем обучать модели. Отбор признаков и обработка пропусков — внутри обучающих фолдов.

Последний блок `view_data.R` показывает первые X в точках присутствия.
Это ещё не обучающая выборка: в ней пока только `y = 1`. ID не включаем в X.
Коды CORINE — категории, их нельзя использовать как непрерывные числа.
Для расстояний у границы понадобится внешний буфер объектов OSM.

BIO8 (`temp_wettest_quarter`) — средняя температура самого влажного квартала, °C;
BIO13 (`precip_wettest_month`) — осадки самого влажного месяца, мм.
Полигоны связаны с `presence.csv` по `record_id`. В GeoPackage сохранены все статусы;
для первичного отбора есть `presence_candidate`. Три нечитаемые геометрии оставлены
пустыми, остальные проблемы отмечены `polygon_valid` — исходные контуры не исправлялись.
Код, комментарии и подписи в `view_data.R` — на английском.

GBIF пока не смешиваем с INVA: 33 точки попадают в полигоны INVA. Перед внешней
проверкой нужно оценить дублирование и пространственную независимость.

Источники и условия использования данных: [data/SOURCES.md](data/SOURCES.md).
Полная первоначальная выгрузка хранится локально в `archive/` и в GitHub не включена.
